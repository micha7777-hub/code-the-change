# Team photos

Put one image per member here, named after the member in lowercase with dashes:

    Evan Honggo Widjojo  ->  evan-honggo-widjojo.jpg
    Nicholas Nurwinata   ->  nicholas-nurwinata.png

Supported: jpg, jpeg, png, webp, avif. Square images around 400x400 look best.
The site picks them up automatically; no code changes needed.
